##  Assignment Overview

This assignment focuses on practical problem-solving using TypeScript concepts from Modules 1, 2, and 3. It covers basic types, optional parameters, union types, type narrowing, readonly tuples, generics, interfaces, Promises, and Object-Oriented Programming (OOP).

##  Technologies Used

- TypeScript
- JavaScript (ES6+)
- Object-Oriented Programming (OOP)

##  Problem Solving

All coding solutions are implemented in a single TypeScript file named `solutions.ts`.

The assignment includes 8 problems covering:

1. Optional and Default Parameters
2. Union Types and Type Narrowing
3. Readonly Tuples
4. Generics and Rest Parameters
5. Interfaces and Array Filtering
6. Generics with Keyof Constraint
7. Classes, Inheritance, and Access Modifiers
8. Async Functions and Promises

##  Learning Outcomes

Through this assignment, I practiced:

- Writing type-safe TypeScript code.
- Working with union types and type narrowing.
- Understanding generics and keyof constraints.
- Using interfaces and readonly tuples.
- Implementing OOP concepts such as inheritance and encapsulation.
- Handling asynchronous operations using Promises and async/await.
